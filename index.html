Halo, saya Musyafa Anasrullah. Fokus utama saya adalah Software Engineering—menciptakan aplikasi dan solusi digital yang tangguh, efisien, dan skala besar. Sebagai mahasiswa Rekayasa Perangkat Lunak, saya terus mendalami ekosistem pengembangan modern, mencakup frontend, backend, database, hingga software architecture. Saya percaya bahwa perangkat lunak terbaik lahir dari clean code dan pemecahan masalah yang sistematis.
